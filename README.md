## Our products

### 🌊 [Luit](https://boatbrothers.in/luit): the AI operating system for construction companies
*Many streams, one current.* Win more work and run every site from one place.

| | What it does |
|---|---|
| **Luit Console** (web) | Tenders and deposits, projects and sites, BOQs, bills and payments, stores and people in one sign-in, with roles for owners, managers, accounts and staff. Site budgets, contractor payments, treasury bills and profit &amp; loss per project. |
| **Luit AI** (Tender Desk) | Ask for tenders in plain words. Luit AI searches official portals (GePNIC, CPPP, GeM), ranks tenders with downloadable files first and fetches the original documents to your desk. Built on Google Gemini. |
| **Luit Field** (Android app) | The site manager's phone: geofenced check-in (fake GPS refused), progress and delivery photos with location, site expenses, leave and offline uploads. |

In daily use by a construction group in Assam. Each client gets its own database, role-based access and an audit trail.

### 🏛️ Interactive museum systems
Touch kiosks and exhibit software that let visitors explore a collection in their own language, with a content manager the staff update themselves. [More](https://boatbrothers.in/museum-systems)

### 🏨 BilXaro hospitality software
Front-desk and GST billing for hotels that keeps working offline.

### 📺 Digital signage &amp; e-governance
Screen networks run from one dashboard, and citizen-facing portals that make public services simpler to use. [More](https://boatbrothers.in/digital-infrastructure)

### 🛠️ Custom software &amp; infrastructure
SaaS, web and mobile apps built to your process; IT park and campus networks; data-centre and cloud operations, supported after launch.
